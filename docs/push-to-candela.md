# Push to Candela (desktop → phone): removed

This feature has been **removed** (issue [#1821](https://github.com/techempower-org/candela/issues/1821)).

"Push to Candela" sent a URL or text from a desktop to the phone through
Candela's InstantDB cloud sync. Candela no longer has cloud sync or an
account: everything stays on your device. The `tools/candela-push` script
was removed along with it.

**To get something onto your phone today:** open the link on the phone and
use **Share → Candela**, or save the text or file somewhere the phone can
open (for example a Google Drive folder you have connected) and import it
there.

A desktop-to-phone push may come back later on a different transport
(tracked by [#1469](https://github.com/techempower-org/candela/issues/1469)).
